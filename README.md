# England-Life-Expectancy-Spatial-Analysis
A rigorous, reproducible spatial data science framework engineered to investigate, model, and quantify the structural and socioeconomic drivers of regional life expectancy disparities across English Local Authorities. This repository contains the underlying pipeline blueprint, econometric models, and machine learning architectures used to map and assess the historic North-South health gradient.

---

### Pipeline Architecture & Methodology
The data science pipeline ingests, cleans, and standardizes cross-sectional public datasets from the 2017 to 2019 period to establish a clean pre-pandemic baseline.

* **Phase 1: Multi-Source Data Wrangling:** Unified official datasets from the Office for National Statistics (ONS) and the UK Government portal using the standard Local Authority District (LAD) code as the relational database key. 
* **Phase 2: Feature Engineering & Skew Control:** Applied logarithmic transformations ($\log_{10}$) to heavily right-skewed infrastructural variables (such as `Population_Density`) to eliminate extreme leverage and stabilize ordinary least squares (OLS) linear assumptions. All independent sub-domains were Z-score normalized to ensure coefficient comparability.
* **Phase 3: Machine Learning & Spatial Segmentation:** Deployed an unsupervised K-Means clustering algorithm on life expectancy metrics to compute a mathematically objective data-driven threshold dividing line ($81.58\text{ years}$). Trained a Linear Support Vector Machine (SVM) classifier on latitude and longitude coordinates to define and plot the geographical vector of England's natural health divide.
* **Phase 4: Explanatory Modeling & Diagnostics:** Developed a series of 5 staged multivariable OLS regressions guided by a Directed Acyclic Graph (DAG) to isolate true structural path mediators from confounding factors. Controlled for heteroscedasticity using HC3 Robust Standard Errors following statistical confirmation via the Breusch-Pagan test, achieving an exceptionally robust final model explanatory power ($Model\ 5\ \text{Adj.}\ R^2 = 0.914$).

### Repository Blueprint

* **`England_Life_Expectancy_Analysis.ipynb`** — The core computational pipeline notebook containing all exploratory data analysis (EDA), data transformations, machine learning classifications, and OLS regression models.
* **`Main_Dataset.csv`** — The final parsed, clean, and parsimonious spatial health dataset consisting of 304 unique local authority entries and zero missing values.
* **`England_Life_Expectancy_Report.pdf`** — The technically comprehensive research report detailing the economic context, statistical validation, and policy implications of the framework.
* **`metadata/`** — Standardized Dublin Core schema definitions and explicit `dc:creator` data governance records.

### Data Provenance & Methodology
The `Main_Dataset.csv` included in this repository was generated by merging five distinct official datasets from the Office for National Statistics (ONS) and the UK Government portal. 

For transparency and reproducibility, the raw source files were sourced from:
* **Life Expectancy Data:** Office for National Statistics (ONS) - Local Areas.
* **Indices of Deprivation (2019):** UK Government Open Data Portal.
* **Demographics & Boundaries:** ONS Open Geography Portal.

*Note: The `England_Life_Expectancy_Analysis.ipynb` pipeline performs all necessary data wrangling, cleaning, and merging required to transform these raw sources into the final analytical dataset.*
